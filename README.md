## 六大核心模块![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/fa6e0a34bf944fda8867961245eaae28.png)

| 模块 | 功能明细 |
| ---- | ---- |
| 数据集管理 | 全流程化管理，预处理步骤化批量执行；工作流随时回溯，防止数据错乱 |
| 可视化标注工具 | 内置矩形框标注工具；多边形/关键点/语义分割及AI辅助标注见V2.0版 |
| 智能数据拆分 | 按比例科学划分训练/验证/测试集；可视化数据分布，自动生成交叉验证集 |
| 模型训练中心 | 支持YOLOv8 / YOLO11 / YOLO26全系；可视化调参+实时监控训练曲线；训练PDF报告自动导出、训练结果管理 |
| 专业评估系统 | 精确率/召回率/F1/mAP全指标一览；多版本模型可视化对比，一键选最优方案 |
| 多格式导出部署 | ONNX/TensorRT/CoreML/TFLite一键导出；模型量化压缩，边缘设备流畅运行；支持本地推理/API服务/边缘端部署 |

## 平台优势
1. **链路完整**：数据准备→标注→训练→评估→部署全流程一体化，免去多个工具切换；
2. **源码开放**：非加密、非阉割，支持二次开发、商业应用；
3. **覆盖全面**：YOLOv8/11/26全系模型 + 多格式导出（ONNX/TensorRT/CoreML/TFLite）+ 多端部署；
4. **落地即用**：内置可视化标注、训练监控、自动出报告，降低使用门槛。
